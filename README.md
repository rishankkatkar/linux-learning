# Linux Learning Log

Learning Linux from scratch, no prior background in cybersecurity or networking. This repo is where I track my journey, whenever I get time to sit down and log it.

Goal: get solid on Linux fundamentals first, then move into Kali Linux and ethical hacking.

## How I Post Here

I don't post a log for every topic right away. My process looks like this:

1. I search the internet and pick something new to learn, usually a command or a concept related to Linux.
2. I study it, then explain it back in my own words (no copy-pasting from what I read).
3. I get quizzed on it. If I score below 75%, I get a hands-on practical task set on the same topic instead of a free pass.
4. Once I clear the practical 100%, I get quizzed again. This loop repeats until I hit 75%+ on a quiz attempt.
5. Only after clearing that bar does the topic actually become a log here.

So every log in this repo represents something I've actually been tested on, not just something I read once and wrote down.

## What's here

- Notes on what I did, what broke, and how I fixed it
- Commands I learned, with context on why they matter
- The mistakes I made during quizzes and practicals, and what corrected them
- Whatever roadmap I'm following at the time

## Why

Documenting this publicly instead of keeping it in a notes app. Forces me to actually explain things instead of half-understanding them, and it doubles as proof of work later.

## Structure

Each log gets its own file, named by topic, whenever I post it. No fixed schedule.
